MES PROJETS / SYSTÈMES

Déploiement d'une infrastructure Docker

Installation, configuration et gestion de plusieurs services informatiques conteneurisés dans un environnement Linux.

Docker Linux Administration système

01 / CONTEXTE

Présentation du projet

Dans le cadre de mes travaux pratiques en BUT Réseaux et Télécommunications, j'ai mis en place un environnement de services informatiques reposant sur Docker.

L'objectif était de déployer plusieurs applications dans des conteneurs indépendants afin de comprendre leur fonctionnement, leur configuration et les interactions entre les différents services.

Ce projet m'a permis de découvrir concrètement la conteneurisation et de travailler sur l'administration de services sous Linux.

02 / ARCHITECTURE

Les services déployés

Plusieurs conteneurs ont été mis en place pour héberger différents services. Chaque conteneur possède un rôle précis dans l'infrastructure.

01 / WEB

Serveur Apache

Hébergement d'un service web à partir d'une image Docker Apache avec PHP.

Apache PHP 8.2 HTTP
02 / DATABASE

Base de données

Déploiement d'un serveur MariaDB destiné à la gestion et au stockage de données.

MariaDB SQL
03 / DNS

Serveur DNS

Installation de Bind9 pour assurer la résolution de noms au sein de l'environnement.

Bind9 DNS Linux
04 / MULTIMÉDIA

Serveur Jellyfin

Déploiement d'un service multimédia permettant d'organiser et de diffuser des contenus vidéo.

Jellyfin VoD
05 / MESSAGERIE

Serveur de messagerie

Mise en place d'un environnement de messagerie à partir de l'image Docker Mailserver.

Docker Mailserver SMTP IMAP

03 / ORGANISATION

Gestion des conteneurs

Les différents services sont organisés dans des conteneurs Docker. Cette approche permet de séparer les applications et de faciliter leur gestion.

J'ai également travaillé avec Docker Compose afin de structurer le déploiement des services et de gérer leur environnement.

Le travail a notamment porté sur la création des conteneurs, la gestion des volumes, des réseaux Docker et des configurations propres à chaque application.

Docker Docker Compose Volumes Réseaux Docker Linux

04 / COMPÉTENCES

Ce que j'ai mis en pratique

Administration Linux

Utilisation de commandes système, gestion des répertoires, permissions et fichiers de configuration.

Conteneurisation

Création, démarrage, arrêt et administration de conteneurs Docker.

Gestion des services

Déploiement de services complémentaires et compréhension de leurs dépendances.

Dépannage

Analyse des journaux, recherche d'erreurs et résolution de problèmes de configuration ou de permissions.

05 / BILAN

Ce que ce projet m'a apporté

Ce projet m'a permis de mieux comprendre le fonctionnement de la conteneurisation et son intérêt dans le déploiement de services informatiques.

J'ai développé mes compétences en administration Linux, en gestion de services et en dépannage. J'ai également appris à organiser une infrastructure composée de plusieurs applications indépendantes.

Cette expérience m'a donné une vision plus concrète de l'administration d'une infrastructure de services et des outils utilisés dans les environnements professionnels.
